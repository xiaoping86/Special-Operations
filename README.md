# 特种作业题库 · lece01

特种作业 **新训 / 复审** 离线刷题项目。

> **工种范围（备注）**  
> 本项目已接入：**低压电工 · 高压电工 · 电焊与热切割 · 高处作业**  
> 可在应用内切换工种题库练习与模拟考试。

本地进度（答题、错题、收藏、考试记录）保存在浏览器，可反复练习。

## 功能

| 功能 | 说明 |
|------|------|
| **顺序练习** | 从第 1 题起刷，选完立即显示对错与解析，进度会记住 |
| **随机练习** | 打乱题目顺序 |
| **模拟考试** | 随机抽 100 题，限时 **60 分钟**，**80 分及格**，交卷后出分 |
| **错题本** | 答错自动进入，可专门重做 |
| **收藏** | 题目页可收藏，方便重点复习 |
| **历史成绩** | 查看历次模拟考试记录 |

## 技术栈

- **Vite 8** + **React 19** + **TypeScript**
- **TanStack Router** 路由
- **Zustand** 本地状态（进度 / 错题 / 收藏 / 考试）
- **Tailwind CSS 4** 界面样式

---

## 本地运行

需要 Node.js 18+（建议 20+）。

```bash
# 安装依赖
npm install

# 开发模式（默认 http://0.0.0.0:8080）
npm run dev

# 类型检查
npm run typecheck

# 生产构建
npm run build

# 预览构建结果
npm run preview
```

常用脚本见 `package.json` 的 `scripts` 字段。

## 使用说明

1. 打开应用后选择工种（低压 / 高压 / 电焊 / 高处）。  
2. 进入 **顺序练习** 或 **随机练习**；选完选项会立刻判分，错题进入错题本。  
3. **模拟考试** 中途可翻题；交卷或到时自动交卷并记入历史。  
4. 清除浏览器站点数据会清空本地进度（请谨慎）。
